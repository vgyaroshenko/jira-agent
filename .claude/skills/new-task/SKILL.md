Створення задачі в Jira. Деталі: $ARGUMENTS (або з контексту розмови).

Виконуй суворо по кроках.

## Крок 1 — Уточни деталі (якщо потрібно)

Якщо користувач не описав що потрібно реалізувати — запитай. Якщо деталі є — пропусти.

## Крок 2 — Тип і мова (ПЕРЕД генерацією)

Використай `AskUserQuestion` з двома питаннями:
- "Що створити?" → Story, Task, Improvement
- "На якій мові?" → UA — українська, RU — русский, EN — English

**Не генеруй задачу до отримання відповіді.**

Для Improvement — перевір спочатку що тип існує в проекті (якщо проект відомий).

## Крок 3 — Визнач мову проекту

```bash
python main.py lang PROJECT_KEY
```

Якщо повертає значення — використовуй його (ігнорує вибір користувача тільки якщо мова явно задана для проекту).

## Крок 4 — Згенеруй задачу

### Story / Task:

```
##DESC##
Вступний опис — що потрібно реалізувати і яку проблему вирішує. 1-2 речення.

##SECTION## 1. Назва вимоги
- Умова або контекст
- Конкретна поведінка

##SECTION## 2. Назва вимоги
- ...

##AC##
AC1. Назва\nУмова.\n✅ Очікуваний результат: конкретний результат.
AC2. ...
```

### Improvement:

```
##DESC##
Поточне обмеження і що потрібно покращити. 1-2 речення.

##SECTION## 1. Поточна поведінка
- Що відбувається зараз (конкретно)

##SECTION## 2. Очікувана поведінка
- Що має відбуватись після покращення

##SECTION## 3. Цінність для користувача
- Чому це важливо

##AC##
AC1. Назва\nУмова.\n✅ Очікуваний результат: конкретний результат.
```

**Правила якості:**
- DESC — не переписуй слова користувача, напиши суть бізнес-проблеми
- SECTION — кожна вимога окрема секція, кожен пункт окремий буллет
- AC — генеруй самостійно навіть якщо не надані, покривай всі ключові сценарії

## Крок 5 — Опублікуй

```bash
python main.py new-task --title "Заголовок" --lang UA --type Story --project GN << 'EOF'
##DESC##
...
EOF
```

Прапор `--related GN-123` — якщо задача пов'язана з іншою (тільки для new-task, не new-bug).
