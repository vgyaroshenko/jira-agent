Перевірка якості задачі $ARGUMENTS.

## Крок 1 — Отримай дані

```bash
python main.py fetch $ARGUMENTS
```

## Крок 2 — Перевір обов'язкові поля

**Для звичайних задач (Story, Task):**
- [ ] Конкретний заголовок (описує суть, не "Оновити сторінку")
- [ ] Непорожній опис
- [ ] Зрозумілий очікуваний результат / AC

**Для багів (TYPE: Bug):**
- [ ] Конкретний заголовок
- [ ] Кроки відтворення
- [ ] Очікуваний результат (ОР / Expected)
- [ ] Фактичний результат (АР / Actual)

## Крок 3 — Дій залежно від результату

**Якщо всі поля є** — повідом "Задача відповідає стандартам якості" і вкажи що саме перевірено.

**Якщо чогось не вистачає** — залиш коментар з тегом репортера:

```bash
python main.py comment $ARGUMENTS --mention REPORTER_ID << 'EOF'
@репортер, будь ласка, доповни задачу:
- [що саме не вистачає]
- [що саме не вистачає]
EOF
```

`REPORTER_ID` є у виводі fetch (поле `REPORTER_ID`).
